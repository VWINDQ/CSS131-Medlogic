# CSS131-Medlogic
CSS131 Project : Logic Programming Paradigm

MedLogic คือระบบวินิจฉัยโรคเบื้องต้นจากอาการ โดยใช้แนวคิด Logic Programming Paradigm ในภาษา Python ผ่านไลบรารีชื่อ Kanren แทนที่จะเขียนโค้ดแบบ "สั่งทีละขั้น" (Imperative) เราจะ ประกาศข้อเท็จจริง แล้วให้ระบบ หาคำตอบเอง

## Setup steps

### 1
```git clone <repo> && cd medlogic```

### 2
```pip install -r requirements.txt```

### 3
```python main.py```

### 4
```pytest tests/ -v```
